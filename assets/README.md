# Visual assets and provenance

The current app icon is generated by `build-icon.sh` from
`branding/obsidian-signal/Lab599-Utility-Obsidian-Final.png`. The script writes
`AppIcon.icns`, `AppIcon.png` and the copy at `../Resources/AppIcon.icns` using
macOS `sips` and `iconutil`. `AppIcon.png` is a 1024-pixel preview; the ICNS
includes standard macOS 1x and 2x icon sizes. The older `AppIcon.svg` and
`branding/legacy-firmware-updater-2.173/` are historical artwork, not the
current build source.

The current artwork includes Lab599-branded elements. The repository also
contains a Lab599 logo and radio photographs under `../Resources/`. Their
presence here does not establish redistribution permission or imply Lab599
endorsement. Written permission is being sought. Existing app ZIP assets are
left intact, and no new app release is planned until permission is clarified.
The model photos in firmware confirmation must remain accurate for each radio.
